# Grok Detect

A small browser detective game. Three cases, a clue desk, interviews, and an accusation that has to name who, why, and how.

Open `index.html` in a browser. No build step.

## Cases

- The Midnight Archive
- Signal Orchard
- The Last Lamp

## Play

1. Open a case.
2. Examine clues and ask questions.
3. File an accusation: suspect, motive, method.
