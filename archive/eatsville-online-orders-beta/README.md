# Grok Eatsville Tycoon

A cartoon 3D restaurant tycoon for phones (three.js, Turbo engine). Cook, serve, keep it sparkly clean for Inspector Grumbleton, fix Ratita Industries gadgets, outsmart Mega Munch and Pizza Palooza, decorate your house, explore, and play co-op with up to 3 friends.

Play: https://lizethbran13-cmyk.github.io/grok-eatsville/
