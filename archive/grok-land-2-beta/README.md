# Grok Land 2

The first Grok game sequel (Suggestion Booth ticket #56 in the Grok Arcade).

- **Boost Zones** – new high-speed Boost Mode: boost meter, grind rails, homing attack, air dash, dash panels and hoops, rings that shield you, real crash consequences, S/A/B/C ranks. First zone: **Meadow Rush**.
- **New worlds** – Candy's Canyon (Red Rock Trail, Mesa Mines), Ratita Industries (Cheese Conveyor), Tortuga Tech (Shell-Tough Test Track), plus all 12 classic Grok Land levels remastered.
- **Better graphics** – tiled textures that never stretch, baked shading, soft shadows, tone mapping, batched static props.
- **Online co-op** – host or join a room right from the title screen (same GrokNet rooms as the Grok Arcade).
- Pet cameos: Luna, Pi-rat, Snowie, Candy and Torty.

Controls: WASD/arrows move · Space jump · E/Shift action (homing attack in Boost Zones) · C/B/L boost · touch controls on phones.

Build: `game.js` is generated from the original Grok Land `game.js` plus the modules in `src/` via `python3 src/patch.py`.
